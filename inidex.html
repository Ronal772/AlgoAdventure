📚 Modul Materi Algoritma & Pemrograman Dasar (Kelas X)

Pelajari ringkasan konsep dari C1 hingga C4 sebelum mengerjakan Pretest, Misi, dan Posttest.

C1 • Mengingat

1. Pengertian & Ciri-Ciri Algoritma

Algoritma adalah urutan langkah-langkah logis dan sistematis untuk menyelesaikan suatu masalah tertentu.

  • Finiteness (Keterbatasan): Algoritma harus berhenti setelah sejumlah langkah terbatas.
  • Definiteness (Kepastian): Setiap langkah didefinisikan secara jelas dan tidak ambigu.
  • Input & Output: Memiliki nol atau lebih masukan dan minimal satu keluaran.
  • Effectiveness (Efektivitas): Setiap langkah sederhana dan dapat dikerjakan dalam waktu masuk akal.
C2 • Memahami

2. Simbol Flowchart & Notasi Algoritma

Algoritma dapat disajikan menggunakan Kalimat Deskriptif, Pseudocode, maupun Flowchart (Diagram Alir).

  • Terminator (Oval): Menyatakan titik Mulai (Start) dan Selesai (End).
  • Input / Output (Jajar Genjang): Proses membaca data masukan atau menampilkan hasil.
  • Proses (Persegi Panjang): Pengolahan data atau perhitungan matematis.
  • Decision / Kondisi (Belah Ketupat): Percabangan keputusan (Ya / Tidak).
C3 • Menerapkan

3. Struktur Kontrol: Percabangan & Perulangan

Dalam pemrograman dasar, alur eksekusi dikendalikan oleh tiga struktur utama:

  • Runtunan (Sequence): Instruksi dijalankan berurutan dari atas ke bawah.
  • Percabangan (Selection / If-Else): Memilih aksi berdasarkan kondisi logika (misal: nilai > 50).
  • Perulangan (Looping / For & While): Mengulang blok instruksi selama kondisi terpenuhi.
C4 • Menganalisis

4. Tracing, Debugging & Efisiensi Algoritma

Kemampuan menganalisis jalannya program untuk menemukan kesalahan (bug) dan memilih solusi paling efisien.

  • Syntax Error: Kesalahan penulisan aturan bahasa pemrograman.
  • Logic Error: Program berjalan tanpa crash, tetapi output keliru akibat salah rumus atau kondisi.
  • Infinite Loop: Perulangan tanpa henti karena kondisi berhenti tidak pernah tercapai.

📐 Rumus Normalized Gain (Hake, 1998)

N-Gain (g) = (Skor Posttest − Skor Pretest) / (Skor Maksimal [100] − Skor Pretest)

g ≥ 0,70 : Tinggi (High Gain) 0,30 ≤ g < 0,70 : Sedang (Medium Gain) g < 0,30 : Rendah (Low Gain)

📊 Integrasi Database Google Sheets (Real-Time Sync)

Hubungkan aplikasi ini ke Google Sheets Anda agar setiap siswa yang mendaftar, login, atau menyelesaikan tes otomatis tercatat di spreadsheet Anda.

Status: Penyimpanan Lokal Aktif (Siap dihubungkan ke Google Sheets)

📋 Panduan Cepat Membuat Database Google Sheets (3 Langkah):

  1. Buka Google Sheets baru, beri nama sheet DataSiswa, lalu klik menu Ekstensi → Apps Script.
  2. Salin dan tempel kode di bawah ini ke editor Apps Script, lalu klik Terapkan (Deploy) → Deployment baru → Aplikasi web (Akses: Siapa saja / Anyone).
  3. Salin URL Aplikasi Web yang muncul dan tempelkan ke kolom di atas.
Kode Google Apps Script (Code.gs) 
function doPost(e) {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName("DataSiswa") || ss.insertSheet("DataSiswa");
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["Waktu Update", "Nama Siswa", "Kelas", "Password", "Waktu Login", "Poin Game", "Skor Pretest", "Skor Posttest", "N-Gain", "Kategori"]);
  }
  var data = JSON.parse(e.postData.contents);
  var rows = sheet.getDataRange().getValues();
  var foundRow = -1;
  for (var i = 1; i < rows.length; i++) {
    if (rows[i][1] === data.name && rows[i][2] === data.kelas) {
      foundRow = i + 1;
      break;
    }
  }
  var rowValues = [new Date(), data.name, data.kelas, data.password, data.lastLogin, data.points, data.pretest ?? "-", data.posttest ?? "-", data.ngain ?? "-", data.ngainCategory ?? "-"];
  if (foundRow > 0) {
    sheet.getRange(foundRow, 1, 1, rowValues.length).setValues([rowValues]);
  } else {
    sheet.appendRow(rowValues);
  }
  return ContentService.createTextOutput(JSON.stringify({ status: "success" })).setMimeType(ContentService.MimeType.JSON);
}
